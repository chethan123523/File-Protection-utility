# File Protection Utility

Encrypt a file locally with a passphrase and download the protected copy.

## Run
Open index.html in a modern browser. For File Protection Utility and Cryptographic Encryption Vault, run through localhost (for example VS Code Live Server) to enable Web Crypto.

## Technology
HTML, CSS and vanilla JavaScript.

## Safety
Educational demonstration only. Do not use as a production security control or enter sensitive real-world data.
